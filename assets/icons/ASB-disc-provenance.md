# ASB disc icon

`local.asb.AgentSwitchBoard.svg` is an unchanged copy of the approved Palatine Mark B.

This is the unchanged, user-approved Palatine Mark B disc icon used by ASB.

SHA256: `c5c9c4472ef283ef8c3eaa1ff3f4758f5e52bb642ed91a3997b36f0a27bf41a0`.

The user approved its use as the ASB app icon. Claude and Codex provider icons stay separate.

The per-user desktop entry uses the installed SVG's absolute path. This lets GNOME Shell load a file icon without its theme cache. [Desktop Entry specification](https://specifications.freedesktop.org/desktop-entry/latest/recognized-keys.html), [GNOME Shell 48.7 icon loader](https://github.com/GNOME/gnome-shell/blob/48.7/src/st/st-icon-theme.c).
