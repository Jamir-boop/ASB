# ASB 1.8.0

ASB 1.8.0 keeps the native toolbar in one row and keeps unread attention until Read by default.

- Preferences and native Close stay fixed at the right. Extra pills and App/state/archive filter chips scroll horizontally. Each chip's × button clears only its filter group.
- At 680 pixels or more, search and Refresh are in the toolbar. Below that width, Search or typing opens a search popover; Refresh is in Preferences > Sessions. Below 320 pixels, typing and Preferences search remain available while the disc and toolbar Search button are hidden.
- Codex and Claude pills are hidden by default. Preferences > Sessions > Show app pills enables them. Narrow windows use the existing app icons. Hiding the pills keeps the app filter.
- The native main view has no numeric counters or count summary. Drawer uses a small dot when it has chats allowed by the archive setting.
- Persistent unread is on when the saved setting is absent or non-boolean. Explicit saved true or false choices stay set. Successful opens acknowledge attention only while it is off.

Production ASB uses Python. The unreleased Rust and Qt frontends and their harnesses were removed after evaluation. Their [Rust results](../benchmarks/python-rust-2026-10-12.md), [acceptance record](../benchmarks/rust-acceptance-2026-10-12.md), [Qt results](../benchmarks/python-qt-2026-10-13.md), and [X11 investigation](../benchmarks/x11-frame-timing-2026-10-13.md) keep the measured facts and limits. The runtime still has 30 files and no external npm dependencies.

## Install or upgrade

For an upgrade, close ASB and use the same installation method as before.

**Debian:**

```bash
sudo apt install ./asb_1.8.0_all.deb
asb
```

**Portable (per-user):**

```bash
tar -xzf asb-1.8.0-linux.tar.gz
cd asb-1.8.0
./install.sh
~/.local/bin/asb
```

Both methods keep the source registry, layout, theme, pins, marks, drawer, and saved Persistent unread choice. Keep the existing config and state folders, including XDG overrides. Files from 1.7.0 remain compatible. Layout schema `1` adds the optional strict boolean `showAppPills`; it is false when absent. Original Codex and Claude stores stay read-only.

## Check limits

The source passed 272 Node tests, 86 native logic tests, and one focused GTK toolbar test. The GTK check used an isolated hidden Xephyr display, Cairo, and synthetic data.

The full GTK widget suite did not run. Real profile edits were not tested. Resize lag and the 240 Hz scrolling limit on the tested X11 stack remain unresolved. This release has no new FPS measurement.
