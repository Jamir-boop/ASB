# ASB 1.15.0

ASB 1.15.0 has a new look for the Messages and Usage windows: they follow the theme accent and the GNOME Large Text setting. The board has clearer cards, a zoom, timed Mute, and more keys. The GNOME top bar and the Android live notification now show two counts. The Android app follows these changes. ASB Bridge is still `0.8.1`. The phone API version and the group schema did not change.

- **Messages:** The round table shows its lines in one neutral gray, and the line or the session that you point to shows in the accent color. Each session name stands on a plate, so no line shows under it. A new count strip under the status bar shows the messages per hour or per day: click an hour or a day to read its messages as a thread. `All messages` at the end of `Recent` opens one thread of the whole period. Threads have a back stack (Back, Escape, Alt+Left, or mouse button 8). The statuses have plain names, and the total shows the count of the messages that were not sent. An empty period offers the next longer period.
- **Usage:** The token types are a ramp of the accent, and the time chart draws an accent `Total` line over thin series lines. A new **Sessions** section shows the 8 sessions with the highest cost (or the most tokens) in the period, and one row with the rest. `All time` takes its steps from the age of the data: days, weeks, or months. In Tokens, the Models and Sessions tables rank by tokens. The machine filter has a check row for each machine. Under the cost, Usage says `if paid at API prices`.
- **Both windows:** Ctrl+1 and the next digits choose the period, and Escape works in steps. An error page shows the reason and **Try again**. The fixed machine, app, and status colors keep apart from the accent. The first and the third machine color changed, so that the first three stay apart with color blindness.
- **Cards:** The `?` and `!` marks are filled discs in the accent color, and Pending cards sort by their mark. A card says **Failed** after a failed task and **Stopped** after a stopped task. An Unknown card says why it is Unknown. A click on a card that ASB cannot open shows the reason and **Show messages**. The board holds the card places while you use the pointer. The Pin button shows an outline pin or a filled pin. Discard has plain names now: **Mark read when done** and **Leave unread when done**. No time shows seconds.
- **Zoom and text size:** Ctrl+wheel, Ctrl+plus, and Ctrl+minus zoom the board in steps from 80% to 200%, and Ctrl+0 resets it. A badge in the toolbar shows a zoom that is not 100%. The board text also follows the GNOME text scale.
- **Timed Mute:** Mute a session for 30 minutes, 1 hour, 8 hours, 1 day, or until Unmute. A muted session asks for nothing until the mute ends. A question or a permission request that it makes after the start of the mute still gets through.
- **Keys:** On a card, Alt+R is Read or Unread, Alt+D the drawer, Alt+M Mute or Unmute, Alt+P Pin or Unpin, and Alt+C the chosen copy kind. Alt+N moves the focus to the next Pending card, and Alt+W runs **Mark read when done**.
- **Drawer:** A Waiting session (a question or a permission request in the original app) can now go in the drawer.
- **Two counts:** The GNOME top bar and the Android live notification show the sessions that need you and the sessions that work. The count of all sessions is gone.
- **Machines:** Preferences > Machines shows the ASB version and build of each machine and the ASB Bridge version of its profiles. An **Outdated** tag marks an older machine or a Bridge profile that needs an update.
- **Pets:** Preferences > Appearance shows the pets as four picture tiles, with a stage where the chosen pet carries a message. The Android app has the Pets setting too.
- **Android:** The Messages and Usage screens, the cards, the marks, and the words follow the PC. A Waiting session can go in the drawer there too.
- **Fixes:** On Windows, a Claude Desktop Code approval no longer stays open after the Claude app replaces its log, and ASB no longer reads a transcript again in full after a restart when its file number is very large. The later questions of a session on another machine show their `?` and play Needs input again. A click next to an open menu or popover now works. The board plays the message light and the pets again while another window has the focus.
- **CI:** While ASB has one user, the three workflows run only on a version tag and by hand. The board widget tests have more time on Debian 13, because their count went from 250 to 556, and each test moves the pointer off the screen first. With the CI fonts (Cantarell and DejaVu), these tests found that Usage at Large Text did not fit a 360 px window with a wide font: the toolbar, the totals, and the tables now fit, and the token type names break between words.

## Install or upgrade

Stop ASB first: select **Quit ASB** in Preferences > Sessions or in the tray icon menu, or run `asb engine stop`. Closing the window does not stop it. Then install with the same method as before:

- **Debian and Ubuntu:** `sudo apt install ./asb_1.15.0_all.deb`
- **Fedora and RHEL:** `sudo dnf install ./asb-1.15.0-1.noarch.rpm`
- **openSUSE:** `sudo zypper install --allow-unsigned-rpm ./asb-1.15.0-1.noarch.rpm` (the RPM has no signature)
- **Arch Linux:** `makepkg -si` in an empty folder with the `PKGBUILD` (needs `base-devel`)
- **Portable:** `tar -xzf asb-1.15.0-linux.tar.gz && cd asb-1.15.0 && ./install.sh`
- **npm (Linux and Windows):** `npm install -g --install-links github:Jamir-boop/ASB#v1.15.0`
- **Nix:** `nix profile install github:Jamir-boop/ASB/v1.15.0`

Then:

1. If the ASB user service runs the engine, restart it: `systemctl --user restart asb.service`. With Nix, also run `asb service install` again.
2. Start ASB: `asb` (portable: `~/.local/bin/asb`).
3. On GNOME Shell 45 to 49, the top-bar extension changed (two counts and the new machine colors). GNOME Shell loads it when it starts again: on X11, press Alt+F2, type `r`, and press Enter; on Wayland, log out and log in.

Update every machine of the group: a machine with an older ASB sends no sessions to the Usage **Sessions** section, and Preferences > Machines marks it **Outdated**. ASB Bridge needs no step: it is still `0.8.1`, and its plugins did not change. The upgrade keeps your profiles, layout, theme, pins, marks, drawer, and Mute. The board zoom starts at 100%. The release files do not include the Android app: build it from `android/` (see the [Android README](../../android/README.md)).

## Check limits

On Linux, the source before the version change (`53d144a`) passed 1541 Node tests (3 skipped), 431 native logic tests, 25 tray tests, 556 GTK widget tests on a hidden X display (GTK 4.18.6, Libadwaita 1.7.6) with the user fonts and again with only the CI fonts, 271 ASB Bridge tests (7 skipped), and 396 Android unit tests with lint. The top-bar extension passed 225 checks in a headless GNOME Shell 48. CI passed on the same commit: it built the packages, checked them in 15 Linux images, ran the 556 board widget tests in Xvfb on Debian 13, and ran the tests on Windows. The release files come from the CI build of the release commit. A Linux PC and two Windows PCs ran the runtime files of `c7e68f2` in real use; the Usage fixes for wide fonts came after it and ran only in the tests. The test phone ran the Android build of `8fd4541`, and the Android app did not change after it. Not tested: GNOME Shell 45, 46, 47, and 49, the stock GNOME Shell theme, GTK 4.12 and Libadwaita 1.4 (CI has no row for them), Claude sessions that run in the cloud, macOS, and FPS on a real display.

See the [publication record](https://github.com/Jamir-boop/ASB/blob/main/docs/OPEN_SOURCE_PLAN.md) for verified release checks.
