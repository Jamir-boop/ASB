# ASB 1.6.1

ASB 1.6.1 reduces native paint work and changes frame sync for ASB on composited X11. Resize lag remains unresolved.

- The existing realize hook disables GTK4 compositor-feedback frame sync only when the surface API exists and X11 is composited. Wayland and noncomposited displays stay unchanged. The GTK4 X11 API is deprecated and has no replacement; its fallback clock may run at about 60 Hz.
- Native columns skip snapshots outside the viewport, including card-motion bounds in the viewport check. Scroll and layout restore skipped snapshots when their columns enter the viewport. All widgets remain allocated, with input, focus, and accessibility unchanged.

Native springs, the renderer, and reduced-motion rules stay unchanged. These fixes require no GTK build or global GPU setting change. No new feature or saved-state format change is included.

## Upgrade

Close ASB. Use the same installation method as before.

**Debian:**

```bash
sudo apt install ./asb_1.6.1_all.deb
asb
```

**Portable (per-user):**

```bash
tar -xzf asb-1.6.1-linux.tar.gz
cd asb-1.6.1
./install.sh
~/.local/bin/asb
```

Both methods keep the source registry, layout, theme, pins, drawer, and unread state. Keep the existing config and state folders, including XDG overrides. Files from 1.6.0 load as they are.

## Check limits

The source passed 269 Node tests and 77 native logic tests. Twenty synthetic Cairo viewport checks also passed. An earlier GTK motion test failed an old expectation. The full GTK widget suite was not rerun after these fixes.

A manual X11 scroll check measured 57.93 FPS in repaint activity. Presented frames were not measured. Resize response was 100.055 ms median and 131.46 ms maximum. These measurements are from one machine. Resize lag remains unresolved.
