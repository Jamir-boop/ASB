# ASB 1.1.0

ASB 1.1.0 adds remote Claude Code rows from local cache and corrects Claude group state.

- Added remote Code sessions from approved local session-list and watch response bodies, with validated app links and duplicate removal.
- Fixed Claude root state, working time, and completion attention while linked background Agents are active. Reads use the existing bounded cache and six-reader limit.
- Native provider warnings hide after five seconds. The same warning stays hidden until it changes or clears. Dashboard fetch errors remain until a successful refresh.

Remote cache data can be incomplete or old. A watch without a full list shows only observed sessions and a warning. Missing or stale worker state gives Unknown. ASB adds no API endpoint, reads no credentials, and makes no remote requests or model calls.

## Upgrade

Close ASB. Use the same installation method as before.

**Debian:**

```bash
sudo apt install ./asb_1.1.0_all.deb
asb
```

**Portable (per-user):**

```bash
tar -xzf asb-1.1.0-linux.tar.gz
cd asb-1.1.0
./install.sh
~/.local/bin/asb
```

Both methods keep ASB settings, pins, and unread state. Keep the existing ASB config and state folders, including any XDG overrides. The default folders are `~/.config/asb` and `~/.local/state/asb`.

ASB remains a local, read-only switcher. See the [user guide](../../ASB.md) and [Privacy](../PRIVACY.md).
