# ASB 1.18.0

ASB 1.18.0 shows Antigravity CLI session cards and status on Windows, shows the CLI badge on OpenCode cards that a terminal shows now, and counts OpenCode background agents and shells again with OpenCode 2.4. ASB Bridge stays at `0.11.0`.

- **Antigravity CLI on Windows:** `asb agent agy-hook install` now works on Windows. The agy hook supplies the session cards and their states, and a card shows Done, Needs input, or Working as on Linux. agy reads the title command only when it starts: restart agy after the install to see session names. Focus, phone answers, and ASB Bridge for agy still need Linux. Checked on Windows 10 with agy 1.5.17.
- **OpenCode CLI badge:** On Linux, an OpenCode card shows the terminal glyph and `CLI` when a live OpenCode TUI shows the session now: a TUI started with `--session <id>`, or a TUI in the session folder whose kitty window title shows the session title, when only one session has that title there. The card still opens the session. The web view and the Android companion also show the badge.
- **OpenCode background counts:** OpenCode 2.4 saves tool calls in a new table. ASB now reads that table and the old message content, so an idle OpenCode card again counts its background subagents and shells. Each shell and each subagent counts once, and a foreground subagent does not count. Databases of older OpenCode 2 builds still work. Background counts show only when **Background counts** is on in Preferences > Appearance.

See the [changelog](../../CHANGELOG.md) for all changes.

## Install or upgrade

Stop ASB first: select **Quit ASB** in Preferences > Sessions or in the tray icon menu, or run `asb engine stop`. Closing the window does not stop it. Then install with the same method as before:

- **Debian and Ubuntu:** `sudo apt install ./asb_1.18.0_all.deb`
- **Fedora and RHEL:** `sudo dnf install ./asb-1.18.0-1.noarch.rpm`
- **openSUSE:** `sudo zypper install --allow-unsigned-rpm ./asb-1.18.0-1.noarch.rpm` (the RPM has no signature)
- **Arch Linux:** `makepkg -si` in an empty folder with the `PKGBUILD` (needs `base-devel`)
- **Portable:** `tar -xzf asb-1.18.0-linux.tar.gz && cd asb-1.18.0 && ./install.sh`
- **npm (Linux and Windows):** `npm install -g --install-links github:Jamir-boop/ASB#v1.18.0`
- **Nix:** `nix profile install github:Jamir-boop/ASB/v1.18.0`

Then:

1. If the ASB user service runs the engine, restart it: `systemctl --user restart asb.service`. With Nix, also run `asb service install` again.
2. Start ASB: `asb` (portable: `~/.local/bin/asb`).
3. ASB Bridge did not change after ASB `1.17.0`. If you upgrade from `1.17.0`, you do not have to install it again. From an older ASB, run `asb bridge install --all` again, open Plugins > ASB Bridge in Codex, trust both hooks, and restart Codex. Check `asb bridge status` after the update.
4. On Windows, to get Antigravity CLI cards, run `asb agent agy-hook install` and restart agy.

Update every machine of the group. An older member still shows its session rows, without the CLI badge on OpenCode cards. The upgrade keeps your profiles, layout, theme, pins, marks, drawer, and Mute. The release files do not include the Android app: build it from `android/` (see the [Android README](../../android/README.md)).
