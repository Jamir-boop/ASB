# ASB 1.12.1

ASB 1.12.1 is a patch release with fixes for Preferences in a narrow window, the place of a read Waiting card, the UI status after you close the board, and the engine CPU use with many chats. ASB Bridge is still `0.8.0`. The phone API, the group schema, and the member routes did not change.

- **Preferences in a narrow window:** At 420 px the five tabs did not fit, so one tab was cut. A window of 600 px or less now shows a list of the sections first. Select a section to open it, and use **Back** or Escape to go back to the list. In a narrow window, the profile dialog now uses the full height, so it starts at the same place for each profile. The Bridge line of a machine with an older ASB now shows `needs ASB 1.12+`, so it fits on one line.
- **Board:** When you mark a Waiting card read, it now moves down to the Idle cards, like the other cards that you mark read. A Waiting card with an unread question or a necessary action stays at the top. After you close the board, `asb agent status` shows `UI: not-open` and the PC sounds stop within about 2 s. Before, this took up to 45 s.
- **Engine:** After a change of a Codex or Claude Desktop Code chat, the engine now checks only the files that changed, so it uses less CPU with many chats. With 700 Codex tasks and 100 Claude chats, the scan after one new line in a task made 12 file checks in place of 911. A full scan still runs at least every 30 s.
- **Android:** A read Waiting session now has the same place in the list as on the board. The release files do not include the app: build it from `android/` (see the [Android README](../../android/README.md)).
- **CI:** The Distros workflow now opens Preferences > Profiles and the profile dialog with GTK 4.12 and Libadwaita 1.4 (AlmaLinux 9), the oldest versions that ASB supports.

See the [changelog](../../CHANGELOG.md) for all changes.

## Install or upgrade

Stop ASB first: select **Quit ASB** in Preferences > Sessions or in the tray icon menu, or run `asb engine stop`. Closing the window does not stop it. Then install with the same method as before:

- **Debian and Ubuntu:** `sudo apt install ./asb_1.12.1_all.deb`
- **Fedora and RHEL:** `sudo dnf install ./asb-1.12.1-1.noarch.rpm`
- **openSUSE:** `sudo zypper install --allow-unsigned-rpm ./asb-1.12.1-1.noarch.rpm` (the RPM has no signature)
- **Arch Linux:** `makepkg -si` in an empty folder with the `PKGBUILD` (needs `base-devel`)
- **Portable:** `tar -xzf asb-1.12.1-linux.tar.gz && cd asb-1.12.1 && ./install.sh`
- **npm (Linux and Windows):** `npm install -g --install-links github:Jamir-boop/ASB#v1.12.1`
- **Nix:** `nix profile install github:Jamir-boop/ASB/v1.12.1`

Then:

1. If the ASB user service runs the engine, restart it: `systemctl --user restart asb.service`. With Nix, also run `asb service install` again.
2. Start ASB: `asb` (portable: `~/.local/bin/asb`).

ASB Bridge needs no step: it is still `0.8.0`, and its plugins did not change. The upgrade keeps your profiles, layout, theme, pins, marks, drawer, and Mute. ASB `1.11.x` and `1.12.x` machines work in one group, and older builds of the Android app work with this engine.

## Check limits

On Linux, the source before the version change (`5acb727`) passed 1046 Node tests (2 skipped), 235 native logic tests, 14 tray tests, 83 GTK widget tests on a hidden X display, 266 ASB Bridge tests (7 skipped), and 196 Android unit tests with lint. On Windows 11 with the same runtime files, `asb agent status` showed `UI: not-open` 0.8 s after a normal close of the board. CI passed on the same commit: it built the packages, checked them in 16 Linux images, opened Preferences > Profiles and the profile dialog with GTK 4.12 and Libadwaita 1.4, and ran the tests on Windows. The release files come from the CI build of the release commit. Not tested: the narrow Preferences window on Windows, Claude sessions that run in the cloud, macOS, and FPS on a real display.

See the [publication record](https://github.com/Jamir-boop/ASB/blob/main/docs/OPEN_SOURCE_PLAN.md) for verified release checks.
