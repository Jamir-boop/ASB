# ASB 1.2.0

ASB 1.2.0 adds the approved Corner pair controls to Comfortable cards and reduces the packaged runtime.

- Select the top-right pin to **Pin** or **Unpin** in ASB. It appears on hover or keyboard focus and stays visible while pinned. Saved pin order, drag reorder, and keyboard menu movement remain available.
- Select the dot beside the pin to **Read** in ASB. Success shows a check for 1.6 seconds; failure keeps the dot. Stale results and feedback cannot hide new attention. Read works with either Persistent unread setting and does not open the chat, change execution, change source read state, or resolve a source question.
- Kept Compact, 68px Comfortable cards, the outer frame, and footer state/time. The circular action overlay reserves space beside the folder and title.
- Reduced the runtime from 42 files in `1.1.0` to 31. Shared server, opener, snapshot, watcher, cache, and file-signature paths replace duplicate code. Removed dead browser helpers and unused CSS. No runtime dependency was added.

Remote Claude cache coverage can still be incomplete or old. A watch without a full list shows only observed sessions and a warning. Missing or stale worker state gives Unknown. ASB reads no credentials and makes no remote requests or model calls.

## Upgrade

Close ASB. Use the same installation method as before.

**Debian:**

```bash
sudo apt install ./asb_1.2.0_all.deb
asb
```

**Portable (per-user):**

```bash
tar -xzf asb-1.2.0-linux.tar.gz
cd asb-1.2.0
./install.sh
~/.local/bin/asb
```

Both methods keep ASB settings, pins, and unread state. Keep the existing ASB config and state folders, including any XDG overrides. The default folders are `~/.config/asb` and `~/.local/state/asb`.

## Check limits

The Corner pair review covers code and logic only. No native UI tests or new native screenshots were run for this change. Native pixel fidelity remains unverified. See the [publication record](../OPEN_SOURCE_PLAN.md) for verified release checks.

ASB remains a local, read-only switcher. See the [user guide](../../ASB.md) and [Privacy](../PRIVACY.md).
