# ASB 1.10.0

ASB 1.10.0 works on more Linux distributions. The release now has an RPM and an Arch `PKGBUILD`, and the repository has a Nix flake. The engine and the board are faster, the readers keep no prompt text, and many problems in ASB Bridge, machine groups, and the Android app are fixed. ASB Bridge is `0.7.0` in this release. This release has no incompatible change.

- **Linux distributions:** The window and the tray icon now work on GTK 4.12 with Libadwaita 1.4 (RHEL, AlmaLinux, and Rocky 9) and on GLib 2.88. On a minimal Fedora 43, GTK 4.20 stopped the window because `libGLESv2.so.2` was missing. `asb doctor` now lists `libglvnd-gles` with the window packages on Fedora, and the RPM recommends it. `asb doctor` also has a **Links** check that names the desktop file for `codex:` links and the one for `claude:` links. The QR code shows only when the Python `qrcode` module and PyGObject cairo support both work. The README has one install block for each distribution family.
- **Packages:** The release has an RPM and an Arch `PKGBUILD` in addition to the `.deb`, the archive, and `SHA256SUMS`. The repository has a Nix flake that pins nixpkgs `nixos-26.05`. The `.deb` and the RPM list the window libraries as Recommends, so they also install on a system with an old GTK, and then ASB runs only the engine. In the `.deb`, **Open ASB** in the tray, the user service, and the autostart entry now use `/usr/bin/asb`. Before, **Open ASB** wrote a per-user app entry that stayed after `apt remove asb`.
- **Commands and sounds (Linux):** The three PC sounds are now WAV files, so they play on systems with no MP3 support. ASB plays them with `pw-play`, then `paplay`, then `aplay -q`. `asb` with an unknown first argument, for example `asb --help`, now prints the usage and exits with code 2. Before, it opened the board and started an engine. The user service no longer restarts every 5 seconds when `asb service install` or `asb setup` follows `asb`. A unit that stays after you remove ASB is now skipped at login.
- **ASB Bridge `0.7.0`:** A peer message now reaches the model once, after a one-line header with the sender name and session ID, so it costs fewer tokens. The header now shows names such as `Fix board rows`, `Revisión del tablero`, or `修复看板`. A name with a comma, a bracket, or a control or invisible character still stays out. `list_sessions` takes the optional `nameContains`. The tool texts are shorter. The model can load the two bridge skills by itself, and `/bridge` and `$bridge` still work.
- **ASB Bridge fixes:** A Codex task no longer puts its inbox socket in the folder of a relay proxy or of another receiver. Before, a relay restart deleted that socket, so nobody could reach the task, and the task could not send. A task can get a receiver again when another process uses the PID of a dead receiver. A message that the bridge cannot send, because the Codex task is neither active nor idle, gets a `delivery-refused` receipt and no longer stops the idle notices of the task. The receipt of a held message that you accept or deny now reaches the other machine. Machine messages work on systems with no `/usr/bin/cat`, for example NixOS. The bridge deletes the state files of tasks that ended more than 30 days ago, so its start uses less CPU and disk.
- **Windows:** ASB Bridge can send by reference to a session on the same PC, and to and from other machines of the group. Before the first byte, the bridge checks that the pipe belongs to the target process of the same Windows user. The receipts need the message relay (Bun). A send by reference needs ASB Bridge `0.6.0` or later: an older bridge gets `bridge-upgrade-required`.
- **Board:** The window opens sooner, because Python keeps the compiled board code in `~/.cache/asb/pycache`, and the launcher runs the board check while the engine starts. The board is faster with many cards and in long sessions: card moves no longer get slower over time, hidden cards no longer stay in memory, and the pointer and the Ctrl numbers restyle only the cards that change. The session menu has **Copy relative reference** and **Copy absolute reference** (`asb:1/...`). The time of a card and the card order no longer change when you open a session: the time is the time of the last turn. A card no longer shows two times in one column, so the empty card slots and the GTK warning "Tried to remove non-child" are gone. One bad card, for example a title cut inside an emoji, no longer stops the board.
- **Engine and readers:** The engine starts faster after a restart. With full file watch coverage, it uses less CPU: it scans when a session file or another machine changes, with a safety scan every 30 seconds. On Linux, a Claude Code CLI card whose process ended during a task now shows Unknown with a reason, not Working for six hours. The Codex source shows a warning when ASB cannot read the Codex session logs. The Codex list is no longer empty on Node.js 20 with long titles, or after a Codex database change. `pending.json` drops the records of rows that ASB did not see for 30 days, unless the row has a pin, a mark, a drawer entry, or Mute. Claude Desktop sessions that moved into a worktree show their current state. A Claude Code CLI session with Remote Control no longer shows as two cards. Cloud cards no longer flicker when the PC clock is a little behind the server. The engine no longer stops when the browser view asks for a file that ASB cannot read.
- **Machines:** A member that is offline for a short time keeps the Working marks and sounds of its rows, so a task does not lose its Done sound or play it again. The first rows of a member play no sounds for old events. A member with a long session list no longer shows offline on all machines: a machine sends its newest 5000 rows at most. A new member no longer polls an old address of the machine that invited it. Archived sessions of another machine no longer show in the Archive filter. An online machine no longer shows offline while another machine is off. A member port that is not from 1024 to 65535 no longer stops the engine.
- **Phone and Android:** The Android companion is a separate app, and the Linux packages and the release files do not include it. Build it from `android/` (see the [Android README](../../android/README.md)). Pairing tries every address of the link, so it works when only ZeroTier or Tailscale reaches the PC. Android drops new alerts after about 50 notifications, so notifications of sessions that you read on the PC now go away. **Check now** shows the notifications that it finds. **Text size** is now **Card text size**, and it changes only the text on the session cards. The phone no longer shows old notifications again after an engine start. You can now change the phone access settings while a saved ZeroTier or Tailscale address is absent.
- **Privacy:** The Codex and Claude readers keep no prompt text. Before, they kept the first and latest prompt and the last answer of each session in memory. They now keep only the time and the kind of each message. ASB also dropped the Codex native pin and the automation hint, which no code read. The saved reader positions hold no text and no paths. The first scan after the upgrade reads the session logs in full.

See the [changelog](../../CHANGELOG.md) for all changes.

## Install or upgrade

ASB `1.8.1` or older has no engine: close its window before the upgrade. If ASB runs, stop it first. Closing the window does not stop the engine or the user service. Select **Quit ASB** in Preferences > Sessions or in the tray icon menu, or run `asb engine stop`. Use the same installation method as before.

**Debian and Ubuntu:**

```bash
sudo apt install ./asb_1.10.0_all.deb
```

**Fedora, RHEL, and their derivatives:**

```bash
sudo dnf install ./asb-1.10.0-1.noarch.rpm
```

**openSUSE** (the RPM has no signature):

```bash
sudo zypper install --allow-unsigned-rpm ./asb-1.10.0-1.noarch.rpm
```

**Arch Linux:** put the `PKGBUILD` in an empty folder, and run this there. `makepkg` needs the `base-devel` package. The `PKGBUILD` downloads the archive of this release and checks its SHA-256.

```bash
makepkg -si
```

**Portable (per-user):**

```bash
tar -xzf asb-1.10.0-linux.tar.gz
cd asb-1.10.0
./install.sh
```

**npm (Linux and Windows):** keep `--install-links` (see [Install with npm](../../README.md#install-with-npm)).

```bash
npm install -g --install-links github:Jamir-boop/ASB#v1.10.0
```

**Nix:**

```bash
nix profile install github:Jamir-boop/ASB/v1.10.0
```

Then do these steps in this order. For a portable install, use `~/.local/bin/asb` in place of `asb`.

1. If the ASB user service or the autostart entry is installed, run `asb service install` again. A unit or entry that the `1.9.0` `.deb` wrote names `/usr/lib/asb/scripts/asb`. It changes to `/usr/bin/asb` only then. With Nix, run it again after each update, because it writes store paths.
2. Start ASB: `asb`.
3. ASB Bridge changed from `0.5.0` to `0.7.0`, and Codex caches the plugin by version. Run `asb bridge install --all` again, open Plugins > ASB Bridge in Codex, trust both hooks, and restart Codex. A Claude Code session loads the new bridge when you start a new session.

Keep the existing config and state folders. The upgrade keeps the source registry, layout, theme, pins, marks, drawer, Mute, and the saved Persistent unread choice. The phone API (version 1), the group schema (version 1), and the member routes did not change since `1.9.0`. ASB `1.9.0` and ASB `1.10.0` machines can be in one group, and an older Android app build still works with this engine. Update every machine of a group when you can.

## Check limits

These checks ran on 2026-10-21 on Linux, on the release source: 767 Node tests (766 pass, 1 skipped), 166 native logic tests, 14 tray tests, 38 GTK widget tests on a hidden X display (GTK 4.18.6, Libadwaita 1.7.6), and 214 ASB Bridge tests with Bun (207 pass, 7 skipped), plus the bridge check with a stock Codex. The 187 Android unit tests ran on 2026-10-20 on the same Android source. A local build of the release source made the `.deb`, the archive, and the `PKGBUILD`, and the 75 runtime files in the `.deb` and in the archive equal the source.

CI passed on commit `35a1986`, the source before the `.deb` compression fix and the version change. The Distros workflow (34 jobs) built the packages once on Ubuntu. In 16 images, it installed the archive and ran `asb doctor`, the engine, the autostart modes, the window in Xvfb (on the rows that can show it), the Python tests, and the uninstall. In 14 of them, it also installed the `.deb`, the RPM, or the `PKGBUILD` and ran `asb doctor` and the engine with `/usr/bin/asb`. Alpine and Void have no package. On Debian 12 and Ubuntu 22.04 (GTK older than 4.12), it checked that ASB runs only the engine. The `nix` job built the flake and started the engine. The Test workflow passed with Node.js 22.13 and 24, and on Windows (the platform-neutral Node tests and the bridge tests only). The five release files come from the CI build of the release commit. The publication record has their checks.

Real Codex and Claude apps, a machine group on real machines, a real phone, macOS, and FPS on the real display were not tested for this release build.
