# ASB 1.13.0

ASB 1.13.0 adds the Messages and Usage windows, a permanent usage history with daily backups, and a top-bar extension for GNOME Shell. The engine and the board now use much less CPU, memory, and network. It also shows Claude approvals as Waiting in more cases. ASB Bridge is still `0.8.0`. The phone API version and the group schema did not change, but this release adds new read routes (see [Install or upgrade](#install-or-upgrade)).

- **Messages window:** A round table of the messages that your agents send each other on all machines of the group: each machine is an arc, the 12 sessions with the newest messages are seats, and a chord joins two sessions that sent messages. The center shows who sent the newest message to whom. Select a chord, a seat, or a recent message to read the thread, with the full text of its newest 60 messages. It counts Claude Code messages (`SendMessage`) and ASB Bridge messages: a message that both transcripts have counts once, and a failed send shows `Not sent`. It opens on `24 hours`. The machines of a group send each other the text of their newest 200 messages; the phone gets no message text. Open it with the ⋮ main menu, Ctrl+M, the tray menu, or **Show messages** in the row panel of a card.
- **Usage window:** The tokens and the API price of the Codex, Claude Code, OpenCode, Antigravity, Grok, and Pi agents on all machines of the group, by machine, app, model, and provider, for `24 hours`, `7 days`, `30 days`, `90 days`, or `All time` (the default). Its chart draws a curve for each app or machine. ASB downloads the LiteLLM price list only while you use Usage, and keeps it for 24 hours. The download sends no ASB data. While a session on this machine works, Usage shows the numbers of the last scan. The next scan starts when no session works, or with the hourly background scan, which waits for at most an hour while sessions work. Open it with the ⋮ main menu, Ctrl+U, or the tray menu.
- **Usage history and backups:** ASB keeps the hourly usage of each machine in a ledger, so Usage keeps the usage of transcripts that an app deleted. Each day at 03:00, ASB saves a backup file with the usage of every machine and keeps the last 5 files. Change the time, the number of files, and the folder in Preferences > Usage, or with `asb usage backup`. To move the usage to another PC, use **Export…** and **Import…** in Preferences > Usage, or `asb usage export <file>` and `asb usage import <file>`.
- **Top bar (GNOME Shell 45 to 49):** A new extension shows the sessions that need you, the sessions that work, and all sessions in the top bar. Its menu lists the newest sessions and the machines, and has **Open ASB**, **Messages**, **Usage**, and **Quit ASB**. While it runs, the tray icon hides itself.
- **Board:** The ⋮ button opens a main menu with **Messages**, **Usage**, and **Preferences** (Ctrl+,). The toolbar shows icons only, and the search field is a row under the toolbar. One click on a card opens it while you search or right after you change a filter, and × or Escape clears the search and all filters. The hover look moves with the cards when they change places, and a click during that motion opens only the card under the pointer. A card in the drawer comes out when its chat works, has a question, or waits for your permission. A failed task, and a task that a usage limit stopped, shows `Stopped` and a `!` mark until you read it. While the board window is not active, a Working card shows whole minutes (for example `4m`) and the cards move with no glide.
- **Lighter engine and board:** While sessions work, the engine reads only the apps whose folders changed, makes no usage scan for a Usage request, and sends a session list event only when the list changed. It compresses the session list and the Messages and Usage reports for the board, and the board downloads a report only when it changed. With 820 sessions, a session list download is 72,699 bytes in place of 1,312,277. The board builds the cards of the columns in view and near them in small steps, uses the Cairo renderer of GTK on X11, and frees the cards and windows that it no longer shows. The board launcher exits 30 s after it starts the board. See the [changelog](../../CHANGELOG.md) for the measured values.
- **Claude approvals:** A Claude Desktop Code chat that waits for a tool approval (for example to click on a site) now shows Waiting after 10 s, also when a background subagent waits. Read on an approval card moves it down to the read cards, and it stays Waiting. On Windows, Claude Code CLI cards and Claude Desktop Code chats now show Waiting for a permission or a question. Claude Code CLI cards now also show on a PC without the Claude desktop app.
- **Windows:** The taskbar button of the board shows the ASB icon and the ASB name, not Python.
- **Android:** The app has Messages and Usage screens (Messages opens on 24 hours, Usage on All time), shows `Stopped` like the board, and keeps a read approval card Waiting. The release files do not include the app: build it from `android/` (see the [Android README](../../android/README.md)).

See the [changelog](../../CHANGELOG.md) for all changes.

## Install or upgrade

Stop ASB first: select **Quit ASB** in Preferences > Sessions or in the tray icon menu, or run `asb engine stop`. Closing the window does not stop it. Then install with the same method as before:

- **Debian and Ubuntu:** `sudo apt install ./asb_1.13.0_all.deb`
- **Fedora and RHEL:** `sudo dnf install ./asb-1.13.0-1.noarch.rpm`
- **openSUSE:** `sudo zypper install --allow-unsigned-rpm ./asb-1.13.0-1.noarch.rpm` (the RPM has no signature)
- **Arch Linux:** `makepkg -si` in an empty folder with the `PKGBUILD` (needs `base-devel`)
- **Portable:** `tar -xzf asb-1.13.0-linux.tar.gz && cd asb-1.13.0 && ./install.sh`
- **npm (Linux and Windows):** `npm install -g --install-links github:Jamir-boop/ASB#v1.13.0`
- **Nix:** `nix profile install github:Jamir-boop/ASB/v1.13.0`

Then:

1. If the ASB user service runs the engine, restart it: `systemctl --user restart asb.service`. With Nix, also run `asb service install` again.
2. Start ASB: `asb` (portable: `~/.local/bin/asb`).
3. On Windows, run `asb engine install` one time, so the Start menu link gets the ASB app ID and the taskbar shows the ASB icon.
4. On GNOME Shell 45 to 49, the portable install turns the top-bar extension on. With the .deb, RPM, Arch, or Nix package, turn it on in the Extensions app or with `gnome-extensions enable asb@jamir-boop.github.io`. GNOME Shell loads it when it starts again: on X11, press Alt+F2, type `r`, and press Enter; on Wayland, log out and log in.

Update every machine of the group: Messages and Usage show a machine with an older ASB as Offline. The phone Messages and Usage screens need ASB 1.13.0 on the PC; older builds of the Android app work with this engine. ASB Bridge needs no step: it is still `0.8.0`, and its plugins did not change. The upgrade keeps your profiles, layout, theme, pins, marks, drawer, and Mute.

## Check limits

On Linux, the source before the version change (`b63f9dd`) passed 1420 Node tests (2 skipped), 326 native logic tests, 21 tray tests, 247 GTK widget tests on a hidden X display, 266 ASB Bridge tests (7 skipped), and 241 Android unit tests with lint. The top-bar extension passed 225 checks in a headless GNOME Shell 48. Test engines with made-up transcripts checked the usage ledger, the export and import, the daily backups, and when a Usage request reads new usage. A Linux PC and two Windows 10 PCs of a machine group ran the runtime files of the same commit: each showed the other two online, and the Usage report of the Linux PC had the usage of all three. CI passed on the same commit: it built the packages, checked them in 16 Linux images, opened Preferences > Profiles and the profile dialog with GTK 4.12 and Libadwaita 1.4, and ran the tests on Windows. The release files come from the CI build of the release commit. Not tested: GNOME Shell 45, 46, 47, and 49, the stock GNOME Shell theme, Preferences > Usage and the narrow Preferences window on Windows, the new Android build on a phone, Claude sessions that run in the cloud, macOS, and FPS on a real display.

See the [publication record](https://github.com/Jamir-boop/ASB/blob/main/docs/OPEN_SOURCE_PLAN.md) for verified release checks.
