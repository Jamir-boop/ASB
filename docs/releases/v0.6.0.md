# Agent Mission Control 0.6.0

> Archived upstream release by forxidian. This is not the ASB release. Historical upstream checks do not validate ASB.

![Agent Mission Control 0.6.0 模型额度与余额](https://raw.githubusercontent.com/forxidian/agent-mission-control/v0.6.0/docs/assets/agent-mission-control-model-services-ui.png)

> 截图完全由虚构 mock 数据生成，不包含本机任务、真实路径、账号标识、凭证或实际额度与余额。

0.6.0 聚焦“任务归属更准确、多模型资源更透明”，同时保持 Agent Mission Control 本地优先、只读和可审计的隐私边界。

## 主要更新

- 新增 Cindy 任务识别与 `cindy://session/<id>` 精确恢复，保留实际 Claude Code / Codex / Pi Harness 信息。
- 将 Cindy Worker、provider SubAgent 和嵌套后代递归归拢到根 Host，去重 Cindy 已拥有的底层 Harness 会话。
- 统一展示 GPT / Codex、Kimi、阿里百炼 Token Plan、Grok 和 DeepSeek 的订阅额度或预付余额。
- 新增额度与时间进度对比、脱敏历史采样、到期预测和“多用 / 少用 / 节奏合适”建议。
- Kimi、Grok 和 DeepSeek 凭证只在请求内存中使用；百炼 Chrome 桥接不申请 Cookie 权限，回退快照仅保存白名单脱敏字段。
- 有界化相似标题比较、处理 `sqlite3` EPIPE，并改善菜单栏助手的本地服务自愈链路。

## English summary

- Added Cindy-aware task ownership, host/subagent reconciliation, and exact Cindy deep-link recovery.
- Added a five-service resource portfolio for GPT / Codex, Kimi, Alibaba Bailian, Grok, and DeepSeek.
- Added quota-versus-time pacing, sanitized local history, confidence-labelled projections, and usage guidance.
- Kept credentials request-local and persisted only allowlisted, owner-readable fallback snapshots.
- Hardened long-running governance, SQLite subprocess handling, and menu-bar service recovery.
