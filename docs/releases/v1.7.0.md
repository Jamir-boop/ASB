# ASB 1.7.0

ASB 1.7.0 moves native settings into one separate Preferences window.

- **Sessions** has app and state filters, archived sessions, and Persistent unread.
- **Appearance** has Compact/Comfortable, shared column width/reset, and GNOME/custom colors.
- **Profiles** contains the existing source table and editor. Its fields, actions, validation, status, authentication, and storage stay unchanged.

Wide windows use left navigation; narrow windows use tabs above the page. Repeated opens raise the same window. Closing Preferences keeps ASB running and keeps the selected section and form edits. Profiles loads only on the first visit and after explicit actions. It adds no timer or background source scan. Main cards, borders, and scrolling stay unchanged.

## Upgrade

Close ASB. Use the same installation method as before.

**Debian:**

```bash
sudo apt install ./asb_1.7.0_all.deb
asb
```

**Portable (per-user):**

```bash
tar -xzf asb-1.7.0-linux.tar.gz
cd asb-1.7.0
./install.sh
~/.local/bin/asb
```

Both methods keep the source registry, layout, theme, pins, drawer, and unread state. Keep the existing config and state folders, including XDG overrides. Files from 1.6.1 load unchanged.

## Check limits

The source passed 269 Node tests, 78 native logic tests, and two focused GTK tests. The GTK checks used an isolated nested X display, Cairo, and synthetic data. Six Preferences captures were inspected at wide and narrow widths.

The full GTK widget suite did not run. Real profile edits were not tested. Resize lag on X11 remains unresolved. This release has no new FPS measurement.
