# ASB 1.3.0

ASB 1.3.0 adds separate app profiles and updates native filters, motion, source state, and theme settings.

- Added a native **App sources…** table and editor for up to eight Codex/Claude profiles. Sources use separate local folders and chat IDs. Their settings have owner-only access. Additional profiles use validated installed launchers that run independently after dispatch. Enable, disable, add, and remove profiles without changing original app data or sign-ins. Default sources stay registered.
- First use can register the known ChatGPT Personal coding profile when source settings are absent and its local store and launcher are present. Ordinary ChatGPT cloud chat history is outside this source.
- Added passive profile dots at the lower-left of provider icons when that app has multiple registered sources. Choose a color or hide a profile dot; hiding keeps its color for later use. Source names remain in search, tooltips, and accessible descriptions.
- Added a Working pill. Working plus Pending shows Working or Pending/unread chats while app, search, and archive filters still apply. Comfortable Idle-read text restores its normal color on hover or focus. One shared hover highlight moves between cards and columns.
- Added smooth horizontal wheel scrolling with a native 180 ms ease-out. Repeated input adds to the target; reversal starts from the visible position. Trackpad input stays direct. Wheel and hover motion respect GNOME animations off.
- Fixed root state, timing, questions, and completion attention for explicitly linked nested Codex subagents. Fixed duplicate Claude bridge rows when local `session_` and remote `cse_` links use the same token. Unrelated chats remain separate.
- Fixed theme picker changes and Apply feedback. Any valid six-digit divider color now applies and saves, including the background color. Dark background and text contrast checks stay in place.
- Updated the synthetic demo source to show four switches between sample Codex and Claude Desktop Code chats. The existing README video link is unchanged. The runtime now has 32 files, including the source registry, with no new runtime dependency.

ASB remains local and reads original app stores read-only. It reads no credentials and makes no remote requests or model calls. Remote Claude cache coverage can be incomplete or old. Missing or stale worker state gives Unknown. Source apps can change their private file formats or app links; ASB may need an update when those interfaces change.

## Upgrade

Close ASB. Use the same installation method as before.

**Debian:**

```bash
sudo apt install ./asb_1.3.0_all.deb
asb
```

**Portable (per-user):**

```bash
tar -xzf asb-1.3.0-linux.tar.gz
cd asb-1.3.0
./install.sh
~/.local/bin/asb
```

Both methods keep the source registry, layout, theme, pins, and unread state. Keep the existing ASB config and state folders, including any XDG overrides. The default folders are `~/.config/asb` and `~/.local/state/asb`.
