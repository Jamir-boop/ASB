# ASB 1.11.1

ASB 1.11.1 is a patch release with fixes for the board, Windows, the engine, ASB Bridge for OpenCode, and the Android app. ASB Bridge is still `0.8.0`. The phone API, the group schema, and the member routes did not change.

- **Row panel:** On X11, **Mute** and the other rows of the row panel did nothing after a normal right-click. They work now. The panel also stays open after **Pin**, **Mark read**, and the other actions. **Mute** and **Unmute** close it, so that you see the mute icon on the card at once.
- **Board:** The mute icon of a card now has the color of the folder name, so you can see it. Waiting cards now have the text colors of Idle cards. After a card move, the wheel on a card copy button switches between Relative and Absolute again. The board no longer lists the `/btw` side chats of the Claude app.
- **Windows:** A Bun from `npm i -g bun` puts only `bun.cmd` on `PATH`, and the message relay cannot start with it. ASB now says that it did not find Bun, in place of an error at each check. For the relay, install Bun with its installer. `asb doctor` now finds an MSYS2 outside `C:\msys64`.
- **Engine:** Your own values of `MALLOC_ARENA_MAX`, `MALLOC_MMAP_THRESHOLD_`, and `MALLOC_TRIM_THRESHOLD_` now stay. The session rows of `GET /api/dashboard` no longer have six fields that ASB does not use: `inCodexSidebar`, `defaultOpenMode`, `desktopName`, `hasUnreadTurn`, `awaitingReview`, and `openLabel`.
- **ASB Bridge for OpenCode:** At the limit of 24 receivers, a new session no longer closes the receiver of a session that another agent waits on (`notify_when_idle`). Before, that agent got a false notice that the session ended. The plugin also calls `session.get` less often. To get these fixes, run `asb bridge install --opencode` again (step 3 below).
- **Android:** The `Done` chip of the live notification now shows for 8 s, also when the phone clock changes. Waiting sessions have the colors of Idle sessions. The release files do not include the app: build it from `android/` (see the [Android README](../../android/README.md)).
- **Privacy:** The placeholder processes of the message relay no longer get the source token of the engine. The OpenCode plugin folder is now private (`0700`). The quit marker `stopped.json` no longer has the engine PID.

See the [changelog](../../CHANGELOG.md) for all changes.

## Install or upgrade

Stop ASB first: select **Quit ASB** in Preferences > Sessions or in the tray icon menu, or run `asb engine stop`. Closing the window does not stop it. Then install with the same method as before:

- **Debian and Ubuntu:** `sudo apt install ./asb_1.11.1_all.deb`
- **Fedora and RHEL:** `sudo dnf install ./asb-1.11.1-1.noarch.rpm`
- **openSUSE:** `sudo zypper install --allow-unsigned-rpm ./asb-1.11.1-1.noarch.rpm` (the RPM has no signature)
- **Arch Linux:** `makepkg -si` in an empty folder with the `PKGBUILD` (needs `base-devel`)
- **Portable:** `tar -xzf asb-1.11.1-linux.tar.gz && cd asb-1.11.1 && ./install.sh`
- **npm (Linux and Windows):** `npm install -g --install-links github:Jamir-boop/ASB#v1.11.1`
- **Nix:** `nix profile install github:Jamir-boop/ASB/v1.11.1`

Then:

1. If the ASB user service runs the engine, restart it: `systemctl --user restart asb.service`. With Nix, also run `asb service install` again.
2. Start ASB: `asb` (portable: `~/.local/bin/asb`).
3. If you use ASB Bridge with OpenCode, run `asb bridge install --opencode` again, and restart OpenCode. Codex and Claude Code need no step.

The upgrade keeps your sources, layout, theme, pins, marks, drawer, and Mute. ASB `1.11.0` and `1.11.1` machines work in one group, and older builds of the Android app work with this engine.

## Check limits

On Linux, the source before the version change (`db3f0c6`) passed 983 Node tests (2 skipped), 215 native logic tests, 14 tray tests, 77 GTK widget tests on a hidden X display, 266 ASB Bridge tests (7 skipped), and 195 Android unit tests with lint. CI passed on the same commit: it built the packages, checked them in 16 Linux images, and ran the tests on Windows. The release files come from the CI build of the release commit. Not tested: a real OpenCode app, `asb doctor` with a real MSYS2 outside `C:\msys64`, macOS, and FPS on a real display.

See the [publication record](https://github.com/Jamir-boop/ASB/blob/main/docs/OPEN_SOURCE_PLAN.md) for verified release checks.
