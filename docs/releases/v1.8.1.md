# ASB 1.8.1

ASB 1.8.1 removes duplicate native toolbar filter controls.

- Working-only uses the Working pill without a second chip. Other restricted state chips remain available.
- App chips appear while the Codex and Claude pills are hidden. Showing those pills removes the duplicate App chip.

Filters and saved settings keep their values. See [ASB 1.8.0](v1.8.0.md) for the other toolbar changes and existing limits.

## Install or upgrade

Close ASB before an upgrade. Use the same installation method as before.

**Debian:**

```bash
sudo apt install ./asb_1.8.1_all.deb
asb
```

**Portable (per-user):**

```bash
tar -xzf asb-1.8.1-linux.tar.gz
cd asb-1.8.1
./install.sh
~/.local/bin/asb
```

Keep the existing config and state folders, including XDG overrides. The upgrade keeps the source registry, layout, theme, pins, marks, drawer, and saved Persistent unread choice.

## Check limits

The patch passed 272 Node tests, 87 native logic tests, and one focused GTK toolbar test. The GTK check covered duplicate Working and App controls on an isolated hidden Xephyr display with Cairo and synthetic data.

The full GTK widget suite and real profile edits were not tested. Resize lag and the 240 Hz scrolling limit on the tested X11 stack remain unresolved. This patch has no new FPS measurement.
