# ASB 1.0.0

ASB puts local Codex and Claude Desktop Code chats in one small native GNOME window. See state and attention, then open the original app. ASB makes no model calls.

![ASB banner](../media/asb-banner.png)

## Included

- Compact and Comfortable views with adaptive columns, horizontal scroll, and saved column width.
- Codex, Claude, Pending, and state filters, plus name/folder search with app prefixes.
- Independent ASB Read/Unread marks, Persistent unread, pins, and mouse/keyboard pin order.
- Current working time when the source provides a start.
- GNOME colors and validated custom dark colors.
- Loopback-only local API, source events, adaptive polling, and read-only original app stores.

See [installation instructions](../../README.md#install-on-linux). The portable archive contains `asb-1.0.0/` and `./install.sh` for per-user installation.

The native runtime needs Python 3 with PyGObject, GTK `>=4.10`, Libadwaita `>=1.4`, Node.js `>=20`, and `xdg-utils`. Node.js `>=22.13` is preferred; older supported versions need `sqlite3`. The Debian package declares SQLite CLI and system runtime dependencies. Codex and Claude Desktop need their URL handlers. These packages do not include the source apps.

## Demo and limits

![ASB synthetic demo](../media/asb-demo.gif)

The scripted Remotion animation uses synthetic chat names and folders. It illustrates controls and is not a recording of private chats or a native UI test. The reproducible source is in [demo/](../../demo/).

States depend on local source writes and can lag. Cold scans can take longer than the polling interval. Claude completion dots are ASB observations, not proof of unread state. ASB does not send prompts, answer questions, run agents, or alter source read state. Native packages are for Linux GNOME; no Windows or macOS installer is included.

See [ASB.md](../../ASB.md), [Privacy](../PRIVACY.md), and [CHANGELOG.md](../../CHANGELOG.md) for details.
