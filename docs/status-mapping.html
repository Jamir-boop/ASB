Rename from the board (not built)

Checked on 2026-10-26: Codex 0.164.0, OpenCode 2.1.4, Claude Code 2.1.310.

  • Codex app and CLI: thread/name/set. An open Codex app may need a reload to show it (not tested).
  • OpenCode 2: session.update with title, through opencode api or the ASB Bridge plugin. opencode api starts a stopped OpenCode service.
  • Claude Code CLI: claude -r <id> -p "/rename <name>", with no model call. Only while the session does not run; its hooks run, and its history gets the command.
  • Claude Desktop Code: no entry point. A write while the app is closed works (tested); the running app writes the old title back.
  • Claude Code on the web: needs a claude.ai login. Not planned.
  • All: ASB would then change app data, so the README and the privacy page must change. Cards of other machines and the phone need the engine of that machine. The bridge send name follows the title.
